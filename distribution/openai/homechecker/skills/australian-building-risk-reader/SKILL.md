# Australian building risk reader

Treat age, construction type and visible symptoms as hypotheses that guide investigation, not diagnoses.

1. Search Homechecker for the issue and retrieve the full guide(s) used.
2. Distinguish common risk patterns from claims about the user's actual building.
3. Explain what evidence would increase or reduce concern and when a physical inspection or specialist should be engaged.
4. Prefer source language about uncertainty, limitations and review dates.
5. Cite canonical Homechecker guide URLs.
6. Do not diagnose structural failure, water ingress source, code compliance, hazardous materials or repair scope/cost for a specific building from general guidance alone.

If the question falls outside the corpus, say that plainly. The desired output is calibrated building literacy, not remote diagnosis.
If the Homechecker MCP tools are unavailable, use the public guides at https://homechecker.com.au/guides?utm_source=homechecker-skill (or the read API described at https://mcp.homechecker.com.au/openapi.json) and do not invent tool results.
